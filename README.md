# A2Z DSA — Solutions

![Language](https://img.shields.io/badge/language-C%2B%2B-blue?style=flat-square)
![Status](https://img.shields.io/badge/status-active-brightgreen?style=flat-square)

Solving DSA from scratch — brute force first, then better, then optimal. Every problem has at least one approach, most have all three.

Topics covered: Arrays · Searching · Sorting · Hashing · Recursion · Strings · Math · Patterns · Stack & Queue

## Structure

Each topic has its own folder. Files are named as `problem-name-approach.cpp` so you can see the progression from brute to optimal at a glance.
